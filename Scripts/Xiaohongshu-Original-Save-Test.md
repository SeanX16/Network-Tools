# 小红书仅保存原视频测试 v1（Quantumult X）

目标：播放继续使用正式回退版的兼容流，只在视频保存接口返回时尝试 1080P 原视频。基于正式回退提交 `b6c59f789d3c25a88b055d83b3b18d58a7b4272f`，2026-11-12 创建。

之前把原视频加入播放候选后，用户报告播放约 1–2 秒 App 闪退；该功能已从正式版撤回。这个独立测试版没有原视频播放注入，不修改播放流的编码、类型、宽高、地址或默认标记。尚未通过 iPhone 保存到相册实测，不能保证不会在保存环节遇到兼容性问题。

## 安装与测试

订阅地址：

https://raw.githubusercontent.com/SeanX16/Network-Tools/main/Scripts/Xiaohongshu-Original-Save-Test.conf

1. 先退出小红书。在 QX 添加本订阅，停用正式整合版、浏览与保存测试版、原版和独立高清保存版，只启用本订阅；不要叠加执行相同接口。
2. 更新资源及引用的 `xhs-original-save-test.js`。如果之前用过导致闪退的原视频播放版本，先清理小红书自己的媒体缓存，避免 App 复用旧文件或播放信息。
3. 重新打开目标笔记，让测试版生成保存信息。先确认播放正常，再使用平时的保存入口。首次保存可能多等待几秒，然后下载原视频；本次原视频约 25.7 MB。
4. 检查相册实际尺寸和声音。目标样本的源文件已验证为 1080×1920、HEVC `hvc1` + AAC；本地完整解码通过不等于 App 保存已经成功。

如出现异常，停用本订阅，重新启用[正式回退版](https://raw.githubusercontent.com/SeanX16/Network-Tools/main/Scripts/Xiaohongshu-Merged.conf)，退出小红书后重开。

## 工作方式与限制

- v4 视频信息流仍执行正式回退版的兼容选流；发送给 App 的 JSON 与正式回退版相同，不新增网络请求。图片原尺寸、实况、去广告、下载按钮与其他原有功能保持不变。
- 如果源尺寸大于选中的兼容流，只向 QX 的 `redBookVideoFeed` 缓存附加该笔记的官方分享地址或原视频 key，以及兼容流的尺寸、时长和记录时间。这些附加字段不会发送给 App，缓存里的 `url` 仍为兼容播放地址。
- 只有实际命中 `/v10/note/video/save` 的响应，且响应笔记 ID 匹配一小时内的缓存，才请求手机分享页并验证原视频 MP4 元数据。最多跟随两次同一笔记的官方域名跳转，不携带 App Cookie 或认证头。
- 仅接受已支持的普通 MP4 编码配置、单 AAC 音轨、未旋转的视频，以及短边 1080、长边不超过 1920、分辨率更高且时长接近的原视频。`ef51` 或无法验证的结构不使用。
- 验证通过后**只替换保存响应的 `data.download_url`**。不把原视频地址写入信息流，不重建播放候选，不把原视频 URL 持久化为播放缓存，也不拦截普通视频 CDN 请求进行重定向。
- 获取失败、缺少缓存、过期、未知格式或超过 6.5 秒，沿用正式版保存逻辑。不能感知后续相册写入是否成功，也不能在 App 保存失败后自动重试另一文件。

**关键限制：**现有用户抓包没有观察到 v10 保存请求，不能确定当前 App 的保存入口会经过此接口。如果 App 直接复用播放缓存写入相册，这个测试版不会将它升级成 1080P，也无法仅凭同一个 CDN 下载请求可靠区分浏览与保存。

## 日志判读

在 QX 的脚本执行记录中查找 `xhs-original-save-test.js` 和前缀 `[仅保存原视频 v1]`：

- `收到 v10 保存响应`：确实命中了本测试版支持的保存接口。
- `找到 1080×1920 hevc`：保存阶段查询到符合元数据检查的原视频。
- `已替换保存地址；播放流未改动`：已将原视频 URL 写入保存响应，尚不代表相册写入完成。
- `使用兼容流或服务器保存地址`：本次未使用原视频。

若保存时没有第一条日志，说明没有观察到这条保存重写路径执行，需要先识别实际保存路径，不能据此继续修改播放流。分享日志时仅提供这些前缀行；完整缓存或 HAR 可能包含私有链接和登录信息。

## 验证范围

使用两份真实信息流结构回放，确认全部播放响应与正式回退版逐字段相同、没有新增请求；模拟 v10 响应只有 `download_url` 变化，播放缓存不变。另验证了低清原视频、`ef51`、错误笔记、登录页、无关跳转、网络失败、超时与迟到响应、旧缓存、过期及损坏缓存的回退，以及图片路由和全部启用规则保持不变。

保存阶段的解析器已真实联网验证分享页及 MP4 分段读取，但触发它的 v10 响应是本地模拟数据。尚无手机上真实命中保存接口、下载原视频并写入相册的成功证据。

本测试版与正式版共用原有四项缓存，未增加缓存键，已有查看/清除任务仍适用。正式整合版继续保持回退状态，不会自动启用本测试功能。
